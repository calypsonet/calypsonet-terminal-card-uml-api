# Changelog

All notable changes to the **Terminal Card API** specification are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this specification adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html),
applied to the specified contract:

- **MAJOR**: breaking change of the contract — a type, an operation, a property or an enumeration value
  is removed, renamed, or its signature, type or semantics change.
- **MINOR**: backward-compatible addition — a new type, operation, property or enumeration value, or a
  clarification that does not alter the existing contract.
- **PATCH**: editorial correction only — wording, layout or diagram fix, with no change to the contract.

> The document revision is tracked in the front-matter *Revision List* of the specification.
